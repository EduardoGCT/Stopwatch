# Stopwatch

Projeto de prática de estudo desenvolvido para consolidar conhecimentos de HTML, CSS e JavaScript. O resultado é um cronômetro simples, funcional e responsivo, com suporte a marcações de tempo.

## Funcionalidades
- Iniciar, pausar e continuar a contagem.
- Resetar o tempo.
- Marcar voltas (marcas) e exibir a lista de tempos registrados.
- Interface simples e direta para uso rápido.

## Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
- Font Awesome (ícones)

## Como usar
1. Abra o arquivo index.html no navegador.
2. Clique em Play para iniciar o cronômetro.
3. Use Pause para interromper e Play para continuar.
4. Use o botão de bandeira para marcar tempos.
5. Use o botão de reset para zerar o cronômetro e limpar as marcações.
